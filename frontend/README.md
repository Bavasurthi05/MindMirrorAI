# Frontend

React + TypeScript + Vite + Tailwind CSS + Framer Motion + Chart.js frontend for the Mental Health Analytics Platform.

## Setup

1. Install dependencies:
   npm install
2. Start the development server:
   npm run dev

## Structure

- src/components/ui: reusable UI components
- src/features: page-specific feature modules
- src/services: API integrations
- src/styles: global styling
